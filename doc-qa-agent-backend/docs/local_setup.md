# Local Setup Guide

This guide walks through running the Document Q&A Agent locally without
Docker, for development and debugging.

## Prerequisites

- Python 3.12
- A Google Gemini API key with access to a chat model (default:
  `gemini-2.5-flash`) and an embeddings model (default:
  `models/gemini-embedding-001`) — get one at
  https://aistudio.google.com/apikey
- (Optional, for the web search tool) A Tavily API key — get one at
  https://tavily.com. Without it, the `web_search` tool will still be
  callable by the model but will return a graceful "unavailable" message
  instead of real results.

## 1. Clone and create a virtual environment

```bash
python3.12 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

## 2. Install dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## 3. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and set at minimum:
GOOGLE_API_KEY=YOUR_GOOGLE_API_KEY

Set `TAVILY_API_KEY` if you want the web search tool to return real results
rather than the graceful fallback message.

All other values in `.env.example` have sensible defaults for local
development (`CHECKPOINTER_BACKEND=memory`, `ENVIRONMENT=development`,
`LOG_JSON=false` recommended locally for readable console logs — see below).

> For local development, it's recommended to override `LOG_JSON=false` in
> your `.env` so log lines are human-readable in the terminal instead of
> single-line JSON (JSON is intended for production log aggregation).

## 4. Add the source document

A sample document (`data/sample_document.pdf`) is already included, covering
a fictional company, Aurora Robotics, and its Aurora M1 warehouse robot.

To use your own document instead, replace `data/sample_document.pdf`, or
point `SOURCE_DOCUMENT_PATH` in `.env` at a different file. Supported
formats out of the box: `.pdf`, `.txt`, `.md`.

## 5. Build the retrieval index

This is a one-time (or "whenever the source document *or* the embedding
model changes") step, kept deliberately separate from serving requests:

```bash
python scripts/run_ingest.py
```

This loads the document, splits it into chunks, embeds each chunk with the
configured Gemini embedding model, and persists a FAISS index to
`vector_db/`.

**Important:** if you ever change `EMBEDDING_MODEL_NAME`, you must re-run
this step. The app validates the persisted index's vector dimension against
the currently configured embedding model at startup and will refuse to
start with a clear error if they don't match.

You should see log output ending in something like:
Vector store persisted to vector_db
## 6. Run the API

```bash
uvicorn app.api.main:app --reload
```

The API will be available at `http://localhost:8000`. Interactive OpenAPI
docs are auto-generated by FastAPI at `http://localhost:8000/docs`.

Check readiness:

```bash
curl http://localhost:8000/health/ready
```

You should see `"vector_store_ready": true`. If you see a 503 here, the
ingestion step (Step 5) either wasn't run or failed — check the startup logs.

## 7. Try it

```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "What is the battery life of the Aurora M1?"}'
```

Try a few questions from `data/sample_questions.md` — Group A questions
should answer without the tool (`tool_used: false`), Group B questions
should trigger the web search tool (`tool_used: true`).

## 8. Run the tests

```bash
pytest -v
```

The test suite uses fakes for the Gemini chat model, embeddings, and
Tavily search (see `tests/conftest.py`), so it runs fully offline — you do
not need a real `GOOGLE_API_KEY` value beyond a non-empty placeholder
string for `Settings` to validate successfully at import time.

## Common issues

| Symptom | Likely cause | Fix |
|---|---|---|
| `/chat` returns a 503 | Vector store not built | Run `python scripts/run_ingest.py` |
| App fails to start with a `VectorStoreDimensionMismatchError` | The persisted index was built with a different embedding model than is currently configured | Run `python scripts/run_ingest.py` to rebuild it |
| `/chat` returns a 502 with "agent failed to produce a response" | Usually a Gemini API error (bad key, rate limit, model access, or an invalid `CHAT_MODEL_NAME`) | Check `GOOGLE_API_KEY`, `CHAT_MODEL_NAME`, and the server logs for the underlying exception |
| Web search always returns "currently unavailable" | `TAVILY_API_KEY` not set | Add it to `.env`, or accept the fallback behavior — it's intentional and non-fatal |
| `pydantic_settings` validation error on startup | `GOOGLE_API_KEY` missing from `.env` | It's a required field; set any non-empty value at minimum |
